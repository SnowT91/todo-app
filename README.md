# Todo App

Interactive Todo application built with HTML, CSS and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in localStorage
- Restore tasks after page reload
- Add tasks with Enter key

## Technologies

- HTML
- CSS
- JavaScript
- localStorage

## Project Goal

This project was created to practice DOM manipulation, event handling, and working with browser storage.
